# Changelog

## 1.0.0 — Field + Store MVP

Added a separate professional dashboard for the FieldShift Field + Store concept. The new project extracts the legacy deterministic engine into a shared module, adds validated field/store messages, simulator scenarios, stale/offline quality states, local buffering, transparent sensor-to-rule translation, store monitoring with `R-STORE-05`, technical evidence, Lite fallback, hardware documentation, and automated tests.

Inherited from `fieldshift-ng`: the northern-Nigeria demo zones, placeholder crop catalog, rules-first safety boundary, Kano/Malam Sani illustrative replay intent, advisory-only forecast/AI boundary, coarse-location privacy stance, and offline-first product direction.

Not included as implemented hardware: ESP32 firmware, physical sensors, BLE/Wi-Fi pairing, rain gauge, water-level electronics, battery system, GSM/SMS delivery, agronomist-reviewed crop parameters, verified annual observations, or real farmer impact evaluation.
